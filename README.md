# 💈 DOM VEIOT BARBEARIA - Sistema de Agendamento

**Site em produção:** https://dom-veiot.vercel.app

Sistema completo de agendamento online desenvolvido para uma barbearia real, com foco em conversão direta para WhatsApp e gestão de horários.

### 🚀 O que o sistema faz

**Para o Cliente:**
- Visualiza serviços (Corte, Barba, Combo)
- Escolhe data e horário disponível
- Clica em "Agendar" e vai pro WhatsApp com mensagem automática

**Para o Dono (Painel Admin):**
- Vê todos os agendamentos do dia
- Controle de horários disponíveis
- Gestão de serviços e preços

### 🛠️ Tecnologias
- React + Vite + Tailwind CSS
- Vercel (deploy automático)
- Git / GitHub

### ▶️ Como rodar
npm install
npm run dev
